⚠️ 缺少依赖：ruamel.yaml

没有它的话，保存配置会把 config.yaml 里的注释全部丢掉（程序会自动备份到 config.yaml.bak，但仍然建议补上）。
执行一次即可： pip install -r requirements.txt 或 pip install ruamel.yaml，然后重启程序。

🔧 Bilibili 配置

检查登录状态…
扫一次就够了 —— 登录凭证会保存下来，下次启动自动恢复，不用重复扫码
等待扫码…
选「每次启动都扫码」时，程序启动会自动打开扫码页；扫不扫都不影响程序继续运行
支持短号 / 完整链接（如 https://live.bilibili.com/12345），保存后立即生效
不填也能连（只能看到部分消息）；填了才能收到完整弹幕数据
